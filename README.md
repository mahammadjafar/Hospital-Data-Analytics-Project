# Hospital Data Analytics Project

## Project Overview
This project focuses on analyzing hospital data to understand hospital performance, patient utilization, bed utilization, and financial performance using different data analytics tools.

## Tools & Technologies
- **SQL:** Data querying, filtering, aggregation, and analysis.
- **Microsoft Excel:** Data cleaning, preprocessing, and analysis.
- **Power BI:** Interactive dashboards and performance reports.
- **Tableau:** Data visualization and analytical dashboards.
- **Microsoft PowerPoint:** Project documentation and presentation.

## Project Modules

### 1. SQL Analysis
Database queries and analysis to extract meaningful insights from hospital data.

### 2. Excel Analysis
Data cleaning, formatting, and preliminary analysis.

### 3. Power BI Dashboard
Interactive dashboards covering:
- Hospital Overview
- Bed Utilization
- Patient Utilization
- Financial Performance

### 4. Tableau Dashboard
Visual analysis of hospital performance through interactive charts and dashboards.

### 5. Project Presentation
A presentation explaining the project, methodology, tools, dashboards, and key insights.

## Project Objectives
- Analyze hospital operational performance.
- Understand bed and patient utilization.
- Evaluate financial performance.
- Identify meaningful trends and insights.
- Present findings through interactive dashboards.

## Project Structure
- SQL
- Excel
- PowerBI
- Tableau
- Presentation

## Conclusion
This project demonstrates the practical application of data analytics tools to transform hospital data into meaningful insights that can support better decision-making.
